**Step B: prompt_tool/knowledge_manager.py（KnowledgeManager）**

创建 KnowledgeManager 类，实现以下方法（完整签名参考 RESEARCH.md Pattern 1 Code Example 1）：

1. `__init__(self)`：初始化 `self._index: dict = {}`、`self._cache: OrderedDict = OrderedDict()`、`self._max_cache_size = 2`、`self._initialized = False`、`self._fallback_active = False`、`self._compiled_dir: Path | None = None`

2. `initialize(self) -> None`：调用 `self._resolve_compiled_dir()` 获取 compiled dir 路径。尝试 open 并 json.load index.json。成功则设置 `self._index = json.load(f)` 和 `self._initialized = True`。FileNotFoundError 或 json.JSONDecodeError 时调用 `self._build_fallback_index()` 并设置 `self._fallback_active = True`。

3. `_resolve_compiled_dir(self) -> Path`：检查 `sys.frozen`（PyInstaller 模式），frozen 时为 `Path(sys._MEIPASS) / "prompt_tool" / "knowledge_packs_compiled"`；否则为 `Path(__file__).parent / "knowledge_packs_compiled"`。使用 pathlib 而非字符串拼接。

4. `match_industry(self, user_input: str) -> list[IndustryMatch]`：
   - `not self._initialized and not self._fallback_active` → 返回 []
   - `len(user_input.strip()) < 2` → 返回 []（防止短输入误匹配 per RESEARCH.md Pitfall 2）
   - 遍历 `self._index` 每个 industry entry：对每个 keyword 打分（if kw in user_input → +3.0, elif kw.lower() in user_input.lower() → +2.0）。score > 0 时创建 IndustryMatch(industry_id, entry["name"], score)
   - 按 score 降序排序返回

5. `load_pack(self, industry_id: str) -> KnowledgePack`：
   - 缓存命中：`industry_id in self._cache` → `self._cache.move_to_end(industry_id)` → 返回 cached pack
   - 缓存未命中：调用 `self._load_from_disk(industry_id)` 加载
   - `len(self._cache) >= self._max_cache_size` → `self._cache.popitem(last=False)` 驱逐最旧
   - 存入缓存并返回

6. `_load_from_disk(self, industry_id: str) -> KnowledgePack`：
   - 尝试 open `self._compiled_dir / f"{industry_id}.json"` → json.load → KnowledgePack(data)
   - 异常时：`self._fallback_active = True` → 调用 `self._build_fallback_pack(industry_id)`

7. `_build_fallback_index(self) -> None`：from .knowledge import INDUSTRIES。遍历每个 industry key，构建 index entry（id/key, name, icon, keywords=list of industry["keywords"], pack_file="", stats 全零）。存入 `self._index`。

8. `_build_fallback_pack(self, industry_id: str) -> KnowledgePack`：从 knowledge.py INDUSTRIES 获取对应 industry dict，构造最小 data dict（meta + 空 terms/roles/workflows/docs/follow_up_trees/pain_points，tasks 从 templates 转换）。返回 KnowledgePack(data)。无需做深度转换——v3.0 兼容即可 per RESEARCH.md Pattern 6。

9. `get_index(self) -> dict`：返回 `self._index`

10. `get_loaded_industry_ids(self) -> list[str]`：返回 `list(self._cache.keys())`

11. `is_fallback_active(self) -> bool`：返回 `self._fallback_active`
