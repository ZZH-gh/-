扩展对话界面支持四种追问消息类型的交互式渲染 per D-08。当前基础版本（Plan 06-01）仅支持 text_input 类型（用户在底部输入框自由回答）。此任务为三种交互类型添加气泡内/气泡下的交互控件。

### 1. 单选按钮渲染（single_choice）

**方法 `_add_single_choice_options(self, options: list)`**
- 参数 options: `[{"value": "b2b", "label": "B2B"}, {"value": "b2c", "label": "B2C"}, ...]`（来自 follow_up_engine next_question 返回的 options 字段）
- per RESEARCH.md Example 5 模式：
  - 创建 `choice_frame = ctk.CTkFrame(self.chat_scrollable, fg_color="transparent")`
  - 遍历 options，每个选项创建按钮：
    - `btn = ctk.CTkButton(choice_frame, text=option["label"], font=CTkFont(size=12), fg_color="#F0F4F8", text_color=colors["text"], hover_color="#D4E6F1", border_width=1, border_color=colors["border"], height=30, corner_radius=6)`
    - `command=lambda v=option["value"]: self._on_option_selected(v)`
  - 按钮水平排列：`btn.grid(row=0, column=i, padx=4, pady=(0,8), sticky="w")`
  - choice_frame grid(row=self._chat_row_count, column=0, sticky="w", padx=(10,60), pady=(0,4)) — 对齐系统气泡左侧
  - `self._chat_row_count += 1`
  - 保存 `self._active_options_frame = choice_frame` 以便后续清理

**方法 `_on_option_selected(self, value: str)`:**
- 添加用户气泡显示选项文本：`self._add_user_message(f"选择：{value}")`
- 销毁选项按钮 frame（`self._active_options_frame.destroy()` if exists）
- 设置生成状态
- 调用 `self._v4_controller.process_answer(value)`
- 注意：此方法不区分单选/多选——单选点击即提交；多选需要额外的确认按钮（见下方）

### 2. 多选复选框渲染（multi_choice）

**方法 `_add_multi_choice_options(self, options: list)`**
- 创建 `choice_frame = ctk.CTkFrame(self.chat_scrollable, fg_color="transparent")`
- 使用 `self._multi_choice_vars = {}` dict 存储 tkinter.BooleanVar 状态
- 遍历 options，每个选项创建一行（水平排列）：
  - `var = tk.BooleanVar(value=False)`
  - `cb = ctk.CTkCheckBox(choice_frame, text=option["label"], variable=var, font=CTkFont(size=12), text_color=colors["text"])`
  - `cb.grid(row=i, column=0, padx=(0,8), pady=2, sticky="w")`
  - `self._multi_choice_vars[option["value"]] = var`
- 确认按钮：`confirm_btn = ctk.CTkButton(choice_frame, text="✓ 确认选择", font=CTkFont(size=11), fg_color=colors["primary"], height=26, command=self._on_multi_choice_confirm)`
- `confirm_btn.grid(row=len(options), column=0, pady=(6,0), sticky="w")`
- choice_frame grid(row=self._chat_row_count, column=0, sticky="w", padx=(10,60), pady=(0,4))
- `self._chat_row_count += 1`

**方法 `_on_multi_choice_confirm(self)`:**
- 收集选中值：`selected = [v for v, var in self._multi_choice_vars.items() if var.get()]`
- 构建显示文本：`"选择了：" + "、".join(selected)` 或 "未选择任何选项"
- `self._add_user_message(display_text)`
- 销毁选项 frame
- 调用 `self._v4_controller.process_answer(", ".join(selected) if selected else "未选择")`

### 3. 确认提示渲染（confirm）

**方法 `_add_confirm_buttons(self, question_text: str)`**
- 创建 `confirm_frame = ctk.CTkFrame(self.chat_scrollable, fg_color="transparent")`
- 两个按钮并排：
  - 「✓ 确认」按钮：`ctk.CTkButton(confirm_frame, text="✓ 确认", fg_color=colors["success"], height=30, command=lambda: self._on_confirm_response(True, confirm_frame))`
  - 「✗ 修改」按钮：`ctk.CTkButton(confirm_frame, text="✗ 需要修改", fg_color="#E74C3C", height=30, command=lambda: self._on_confirm_response(False, confirm_frame))`
- 按钮水平排列 grid(row=0, column=0/1, padx=4, pady=(0,8))
- confirm_frame grid(row=self._chat_row_count, column=0, sticky="w", padx=(10,60), pady=(0,4))
- `self._chat_row_count += 1`

**方法 `_on_confirm_response(self, confirmed: bool, frame)`:**
- 添加用户气泡：`self._add_user_message("确认" if confirmed else "需要修改")`
- 销毁 frame
- 如果 confirmed：调用 `self._v4_controller.process_answer("是")`
- 如果 not confirmed：调用 `self._v4_controller.process_answer("需要修改")`
