# Phase 6: UI - UI Design Contract (UI-SPEC)

## Overview

v4.0 对话式交互界面。用户进入应用后直接看到对话界面，输入需求后系统引导追问，生成后切换到结果展示界面。

## Page Layout

### Mode: Page Switching (D-01, D-02)

Two pages switching via Frame grid_remove/grid:

1. **对话界面 (chat_frame)** — 默认首页
2. **结果界面 (result_frame)** — 生成后切换

Header bar and status bar remain persistent across both pages.

## Interaction Spec

### 对话界面交互 (D-06, D-07)
- 问答卡片水平交替：用户输入显示在左侧（紧凑型），系统回复在右侧（展开式）
- 追问展示为右侧系统卡片，用户在底部输入框自由填写答案
- 底部输入行固定：`[输入框] ▶ [🎯 立即生成]`
- 发送按钮 (▶) 提交当前输入，\n 换行用 Shift+Enter
- 滚动区域自动滚到底部

### 逃生门 (D-09, D-10)
- "🎯 立即生成"按钮始终位于输入框右侧
- 任意时刻点击，跳过剩余追问，用当前已收集信息直接生成
- 调用 ConversationEngine.generate_complete()

### 结果界面交互 (D-04, D-05)
- 三卡横向等宽对比，使用 `uniform="card"` 权重
- 每张卡：标题标签 + 只读 CTkTextbox + "📋 复制"按钮
- 顶部 Header 增加"← 返回对话"按钮和"新对话"按钮
- 返回对话时保留当前对话历史，可继续修改

### 优化面板 (D-11, D-12, D-13)
- 右侧固定侧栏面板，默认展开
- "📝 追加要求" — 多行输入框
- "风格" — 下拉选择（更简洁/更详细/更专业/更通俗）
- "限制" — 多选框
- "🔄 重新生成"按钮 → 重新生成全部三卡
- 面板可收起/展开（按钮在面板标题栏），收起后三卡区域占满

## Visual Style

- Colors: 复用 v3.0 色板（primary #2B579A, body #F0F2F5 等）
- 用户气泡背景色: primary blue tint
- 系统气泡背景色: white/card color
- 字体大小: 13px 正文, 11px 辅助
- Header: 同 v3.0 深蓝底色

| Component | Type | Description |
|-----------|------|-------------|

| ResultPage | CTkFrame | 结果界面容器，包含三卡 + 优化面板 |
| ChatBubble | CTkFrame | 单个对话气泡（用户左/系统右） |

| OptimizationPanel | CTkFrame | 右侧优化侧栏（收起/展开） |
| AppController | class | 控制页面切换、对话流编排（新增或集成到 PromptToolApp） |

## Success Criteria Mapping

| UI Decision | Acceptance Criteria |
|-------------|-------------------|
| D-01 (页面切换) | 初始显示对话界面，生成后切换到结果界面 |
| D-03 (三卡对比) | 结果界面三列等宽排列，scrollable |
| D-04 (返回对话) | 结果界面顶部有返回按钮，点击回到对话 |
| D-06 (水平交替) | 用户气泡左对齐，系统气泡右对齐 |
| D-07 (底部输入) | 输入框+发送按钮+逃生门固定于底部 |
| D-09 (逃生门) | 生成按钮始终可见，点击后跳过追问直接生成 |
| D-11 (优化面板) | 右侧面板含追加输入+风格选择+限制选项 |
| UI-01 | 完整对话流程：输入→追问→生成→展示 |
| UI-02 | 任意时刻点击生成按钮跳过追问 |
| UI-03 | 优化后重新生成三卡 |
