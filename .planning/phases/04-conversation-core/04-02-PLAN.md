  <action>Create prompt_tool/follow_up_engine.py.

Define FollowUpEngine class with:

__init__(self): Initialize self._tree: dict | None = None, self._current_node_id: str | None = None, self._question_count: int = 0, self._max_questions: int = 3 (CONV-04), self._collected_info: dict[str, str | list[str] | bool] = {}, self._degradation_level: dict[str, int] = {} (tracks degradation per node), self._completed: bool = False.

load_tree(self, industry_id: str, task_type: str) -> dict | None: Uses knowledge_manager singleton — knowledge_manager.load_pack(industry_id).get_follow_up_tree(task_type). Returns None if pack or tree not found. On success: stores self._tree = tree_dict, sets self._current_node_id = tree["root_node_id"], resets self._question_count = 0, self._collected_info = {}, self._degradation_level = {}, self._completed = False. Returns the current question dict from _get_node(self._current_node_id).

_get_node(self, node_id: str) -> dict | None: Look up node_id in self._tree["nodes"]. Return None if not found.

get_current_question(self) -> dict | None: Return _get_node(self._current_node_id) with an added "question_number" field (self._question_count + 1) and "remaining" field (self._max_questions - self._question_count). Return None if _completed or no tree loaded.

process_answer(self, answer: str | list[str] | bool) -> dict: Process user's answer to current question.

1. Get current node. If no node → return completion signal {"action": "complete", "collected_info": self._collected_info}.

2. Store answer: self._collected_info[node["info_key"]] = answer. Record via session_manager.update_extracted_info(node["info_key"], str(answer)).

3. Increment self._question_count += 1.

4. Determine next node:
   - **single_choice**: answer is a str matching one of the option values. Look up node["children"][answer] for next node_id. If answer doesn't match any option → use node.get("fallback_node_id").
   - **multi_choice**: answer is a list[str]. Join as comma-separated string for storage. Use the first selected value to look up children: node["children"][answer[0]]. If no match → use fallback_node_id.
   - **text_input**: answer is a str. Look up node["children"].get("_any") for next node_id. If no "_any" key → use fallback_node_id.
   - **confirm**: answer is a bool. If True → use node["children"].get("yes"), else → use node["children"].get("no") or fallback_node_id.

5. Check if should stop:
   - If next node is a leaf (next_node["is_leaf"] is True) → self._completed = True. Return {"action": "leaf_reached", "node": next_node, "collected_info": self._collected_info}.
   - If self._question_count >= self._max_questions (CONV-04) → self._completed = True. Return {"action": "limit_reached", "message": f"已收集 {self._question_count} 个问题的答案，进入生成阶段", "collected_info": self._collected_info}.
   - Otherwise → set self._current_node_id = next_node_id. Return {"action": "next_question", "question": self.get_current_question(), "collected_info": dict(self._collected_info)}.

has_more_questions(self) -> bool: Return not self._completed AND self._question_count < self._max_questions AND self._current_node_id is not None AND (not self._get_node(self._current_node_id) or not self._get_node(self._current_node_id).get("is_leaf", False)).

handle_dont_know(self) -> dict: 3-level degradation per CONV-05.

1. Get current node. Track degradation: node_key = self._current_node_id; current_level = self._degradation_level.get(node_key, 0).

2. **Level 1 (simplify question)**: If current_level == 0: self._degradation_level[node_key] = 1. Return {"action": "degraded_question", "level": 1, "original_question": node["question_text"], "simplified_question": f"简单来说：{node['question_text']}（你可以用简单的话描述一下吗？）", "node": node}.

3. **Level 2 (broader classification via fallback)**: If current_level == 1: self._degradation_level[node_key] = 2. If node.get("fallback_node_id"): move to fallback node. self._current_node_id = node["fallback_node_id"]; fallback = self._get_node(node["fallback_node_id"]). Return {"action": "broader_question", "level": 2, "message": "没关系，我们换个更宽泛的问题：", "question": self.get_current_question()}. If no fallback_node_id → go directly to level 3.

4. **Level 3 (example guidance)**: self._degradation_level[node_key] = 3. Generate example guidance based on node["question_type"]: for single_choice → "例如，你可以选「{node['options'][0]['label']}」或「{node['options'][1]['label']}」" (use first two options if available); for multi_choice → "例如，你可以选择「{node['options'][0]['label']}」和「{node['options'][1]['label']}」"; for text_input → "例如，你可以输入类似「...」的简短描述"; for confirm → "你可以回答「是」或「否」". self._completed = True. Return {"action": "example_guidance", "level": 3, "message": "以下是一些示例供参考：", "examples": examples_text, "collected_info": self._collected_info}.

get_collected_info(self) -> dict: Return a shallow copy of self._collected_info.

reset(self): Reset all internal state to __init__ defaults.

Edge cases: load_tree() called with industry_id not in index → return None. load_tree() called with task_type that has no follow_up_tree field in task definition → return None. process_answer() called when no tree loaded → return {"action": "error", "message": "没有加载追问树"}. get_current_question() when no tree loaded → return None.</action>
