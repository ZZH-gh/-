Declares a class-level _VALID_TRANSITIONS dict mapping each state to a set of allowed next states:
- IDLE → {ANALYZING}
- ANALYZING → {CONFIRMING, CLARIFYING, ERROR}
- CONFIRMING → {FOLLOWING_UP, GENERATING, IDLE, ERROR}
- CLARIFYING → {CONFIRMING, ANALYZING, ERROR}
- FOLLOWING_UP → {FOLLOWING_UP, GENERATING, ERROR}
- GENERATING → {COMPLETE, ERROR}
- COMPLETE → {IDLE}
- ERROR → {IDLE}
- PAUSED → {IDLE, ANALYZING}

_transition(self, new_state: ConversationState): private method. If new_state not in _VALID_TRANSITIONS[self.state], raise ConversationError(f"Invalid transition: {self.state.name} -> {new_state.name}"). Otherwise set self.state = new_state.

start(self, user_input: str) -> dict: Public entry point. Guard: if user_input is empty/whitespace-only → transition to ERROR, return {"state": "ERROR", "error": "输入不能为空", "action": "show_error"}. Record system turn: "检测到行业「{industry_name}」、任务「{task_name}」（置信度 {confidence}%），是否正确？". Record system turn confirming the change. 3) Check if follow-up tree exists: load pack via knowledge_manager.load_pack(intent.industry_id), check pack.get_task(task_name) for "follow_up_tree" field. If tree exists → transition to FOLLOWING_UP, return {"state": "FOLLOWING_UP", "action": "start_follow_up", "tree_id": tree_id}. If no tree → transition to GENERATING, return {"state": "GENERATING", "action": "generate"}. Store the action in self._pending_action.

handle_skip(self) -> dict: Transition to GENERATING (from FOLLOWING_UP or CONFIRMING). Record system turn "用户选择跳过追问，直接生成". Return {"state": "GENERATING", "action": "generate"}.

get_state(self) -> ConversationState: Return current state.

get_pending_action(self) -> dict: Return self._pending_action.

All state handler methods record system turns via self._sm.add_turn("system", message, "info" or "question").
