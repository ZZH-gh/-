## ConversationEngine public API (Plan 01 + Plan 02)
```python
from prompt_tool.conversation_engine import ConversationEngine, ConversationState

engine = ConversationEngine()  # creates IntentClassifier + FollowUpEngine internally

engine.start(user_input: str) -> dict
# Returns: {"state": "CONFIRMING"|"CLARIFYING"|"ERROR", "action": "request_confirmation"|"ask_clarification"|"show_error",
#           "industry": {"id": str, "name": str}, "task": {"key": str, "name": str},
#           "confidence": int, "message": str,
#           "matched_industries": [...], "matched_tasks": [...]}
# Or: {"state": "CLARIFYING", "action": "ask_clarification", "message": str}
# Or: {"state": "ERROR", "action": "show_error", "error": str}

engine.handle_confirmation(confirmed: bool, industry_override: str|None=None, task_override: str|None=None) -> dict
# Returns: {"state": "FOLLOWING_UP", "action": "start_follow_up", "first_question": dict, "tree_id": str}
# Or: {"state": "GENERATING", "action": "generate"}
# Or: {"state": "IDLE", "action": "reset"}

engine.handle_answer(answer_text: str) -> dict
# Returns: {"state": "FOLLOWING_UP", "action": "show_question", "question": dict, "collected_info": dict}
# Or: {"state": "GENERATING", "action": "generate", "collected_info": dict}

engine.handle_dont_know() -> dict
# Returns: {"state": "FOLLOWING_UP", "action": "show_question", "question": dict, "message": str}
# Or: {"state": "GENERATING", "action": "generate", "collected_info": dict}

engine.handle_skip() -> dict
# Returns: {"state": "GENERATING", "action": "generate"}

engine.get_state() -> ConversationState
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input via CTkTextbox → ConversationEngine.start() | Free-text crosses from UI widget into engine |
| User answers via radio/checkbox/text → ConversationEngine.handle_answer() | Structured answers cross into state machine |
| UI event handlers → daemon thread dispatch | Cross-thread boundary (Tkinter main thread vs daemon) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-09 | Tampering | app.py _on_generate | mitigate | Input validation: reject empty/placeholder text before starting conversation; warn if conversation_active is already True to prevent duplicate flows |
| T-04-10 | Denial of Service | app.py daemon thread dispatch | mitigate | Daemon thread follows existing pattern (daemon=True, no blocking); all UI mutations go through self.root.after(0, ...) per Tkinter thread safety convention; no new synchronization primitives needed |
| T-04-11 | Tampering | app.py answer widget values | mitigate | Answer values extracted from customtkinter widget variables (StringVar, BooleanVar) — Tkinter handles widget lifecycle; multi_choice answers validated to be non-empty list before submission; text_input stripped of leading/trailing whitespace |
| T-04-12 | Information Disclosure | app.py error display | mitigate | Errors from ConversationEngine shown via messagebox.showerror with user-friendly Chinese messages only; stack traces never displayed to user; daemon thread exceptions caught and dispatched to _on_error |
| T-04-SC | Tampering | pip install (no new packages) | accept | No new dependencies; all UI uses existing customtkinter + tkinter stdlib |
</threat_model>
