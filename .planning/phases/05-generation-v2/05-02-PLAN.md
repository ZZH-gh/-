**Strategy 1: `_direct(self) -> str`** — Fastest path, minimal injection

Injection profile: 1 point only (`_inject_quality_standards`), no role preamble, no conversation context, no output structure, no anti-patterns.

Structure:
1. Task line (`_task_line()`)
2. Conversation context note (ONLY if `self.summary` is non-empty AND `self.summary` contains user intent; limit to 1-2 sentence summary prefixed by `"## 背景\n"`)
3. `"## 要求\n"` + `_bullets()` (use the generic version, not _spec_req — direct strategy keeps it broad)
4. `_inject_quality_standards()` — the only injection; use a concise version (1-2 lines max, no heading)
5. `_format_line()`
6. `_tone_hint()`

Target output: ~150-300 chars beyond task description. The output should feel like a "quick accurate prompt" — practical, no fluff.

**Strategy 2: `_roleplay(self) -> str`** — Medium depth, role-focused

Injection profile: 2 points (`_inject_role_depth` + `_inject_quality_standards`). No conversation context, no output structure, no anti-patterns.

Structure:
1. Role preamble: `"你是一位" + self._get_role() + "。"` + role depth paragraph from `_inject_role_depth()` (if non-empty)
2. `"## 任务\n"` + `_task_line()`
3. `"## 要求\n"` + `_bullets()`
4. `_inject_quality_standards()`
5. `_format_line()`
6. `_tone_hint()`

Target output: ~300-500 chars. The role depth section should give the AI an identity with context (KPIs, pain points) so it generates role-appropriate output.

**Strategy 3: `_detailed(self) -> str`** — Full depth, complete structure

Injection profile: ALL 4 injection points. Plus conversation context section and full formatting.

Structure:
1. Role preamble: `"你是一位" + self._get_role() + "。"`
2. `"## 背景\n"` + `_bg()` (project background from confirmed info + original input)
3. Conversation context section: if `self.summary` is non-empty: `"\n## 对话上下文\n" + self.summary`
4. `"## 任务\n"` + `_task_line()`
5. `_inject_all()` — all 4 injection points in D-06 order (role depth -> quality -> output structure -> anti-patterns)
6. `"## 要求\n"` + `_bullets()` (use _spec_req first if available, detailed strategy should be industry-specific)
7. `"## 输出格式\n"` + `_format_line()`
8. `"## 注意事项\n"` + `_tone_hint()` + extra note: `"- 直接输出结果，不需要额外解释\n- 内容要贴合" + self.industry_name + "领域的实际情况"`

Use ONE random quality-hint from this pool for the extra note (same pattern as v3.0 detailed):
```

```

Target output: ~500-800 chars. Structured like a professional prompt engineering document.
