Build a list of filter rules. Each rule is a dict with at minimum `{"type": str, "trigger_phrases": list[str], "replacement": str}` or `{"type": str, "pattern": str, "replacement": str}`.

PRIMARY layer — Pain point driven (D-15, D-18):

If `self._pack` is not None:
```
for pp in self._pack.get_pain_points():
    typical_phrases = pp.get("typical_phrases", [])
    what_not_to = pp.get("what_not_to_do", "")
    if typical_phrases:
        rules.append({
            "type": "pain_point",
            "trigger_phrases": typical_phrases,
            "description": pp.get("name", ""),
            "replacement": f"[注意：避免{pp.get('name', '')}]",
        })
```

This uses the data confirmed to exist in internet_it.json (pain_points[].typical_phrases, pain_points[].what_not_to_do, pain_points[].name).

rules.extend([

**Part B: `_filter(self, text: str) -> str`**

Apply all rules from `_build_anti_pattern_rules()` to the input text. The rules list is built once and cached — call `_build_anti_pattern_rules()` once and store result on `self._anti_pattern_rules` (lazy init in _filter).

Processing order:
1. FIRST: Apply pain_point rules (type == "pain_point") — for each rule, check if any `trigger_phrases` element appears in the text. If found, replace the triggering phrase with the rule's `replacement` string (D-17: auto-replace, user sees filtered version).
2. SECOND: Apply regex authority/stereotype rules (type == "authority" or "stereotype") — use `re.sub(pattern, replacement, text)`. For authority type: the replacement may be empty (removing the claim) or a softened version. For stereotype type: remove the pattern entirely.

Return the filtered text, stripped of leading/trailing whitespace.

Cache strategy: Set `self._anti_pattern_rules = None` in `__init__`. In `_filter()`, check `if self._anti_pattern_rules is None: self._anti_pattern_rules = self._build_anti_pattern_rules()`. This avoids rebuilding rules on each call.
