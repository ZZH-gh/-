# 智能提示词工坊 (Smart Prompt Workshop)

## What This Is

一款面向各行业普通用户的桌面工具。用户只需输入一句简短的需求描述，工具通过行业专家级知识库和对话式引导，生成可以直接扔给 AI（ChatGPT/Claude/文心一言等）执行的高质量、细致入微的提示词。

当前已有 v3.0 基础版本（Python + customtkinter 桌面应用，16行业覆盖，3种策略，30MB单文件exe），但提示词偏模板化、缺乏行业深度。v4.0 将重点攻克"细致入微"的问题。

## Core Value

**让不懂写提示词的普通人，用最简短的语言，最快拿到能让AI真正干活的、有行业深度的提示词。**

## Requirements

### Validated

已存在于 v3.0 代码库中的能力：

- ✓ 16 大行业关键词识别与分类 — existing
- ✓ 3 种提示词生成策略（直给式/角色委派式/完整详细式） — existing
- ✓ 基于关键词的用户意图分析引擎 — existing
- ✓ customtkinter 桌面 GUI（输入→分析→展示→导出） — existing
- ✓ PyInstaller 单文件 exe 打包 — existing
- ✓ 完全离线运行，零依赖 — existing

### Active

- [ ] **KNOW-01**: 行业专家知识包体系 — 为每个核心行业建立结构化的深度知识（术语、流程、指标、最佳实践、常见场景），替代现有扁平关键字列表
- [ ] **KNOW-02**: 知识包自动构建管线 — 从网络/文档中研究并自动生成行业知识包的流水线
- [ ] **CONV-01**: 对话式需求挖掘引擎 — 用户输入后，系统像资深顾问一样反问补全信息（行业、角色、场景、具体目标、输出偏好）
- [ ] **CONV-02**: 深度追问逻辑树 — 每个行业/任务有对应的追问路径，能层层深入挖出真正需求（而非随机问几个问题）
- [ ] **GEN-01**: 场景感知提示词生成器 — 基于知识包+对话结果，生成有行业深度、自然、不模板化的提示词
- [ ] **GEN-02**: 3-5个核心行业做到极致深度 — 首批深耕互联网/IT、销售/零售、教育、金融、制造业
- [ ] **UI-01**: 对话式交互界面 — 输入区→对话流→结果展示，自然的一问一答体验
- [ ] **UI-02**: 知识包可视化 — 用户可以查看当前行业知识包的内容，了解工具"懂什么"
- [ ] **PKG-01**: 离线exe打包 — 知识包内置于exe中，不依赖在线API
- [ ] **QA-01**: 提示词质量评估 — 建立评估机制，确保生成的提示词确实有深度且可用

### Out of Scope

- 在线实时AI API生成（知识包通过AI研究构建后固化到离线包中，运行时不调API） — 离线优先原则
- 移动端/Web端（v4.0专注Windows桌面，后续再考虑）
- 用户自定义行业包编辑器（v4.0先由我们来构建知识包）
- 多语言支持（v4.0专注中文，后续考虑）

## Context

现有 v3.0 代码库分析要点：

1. **知识层**（`knowledge.py`，41KB）— 16行业关键词列表 + 任务类型 + 角色定义，扁平结构，缺乏深度
2. **分析引擎**（`engine.py`，12KB）— 基于关键词权重的行业/任务匹配，准确度已修复但仍是"关键词"层面
3. **生成器**（`generator.py`，21KB）— 模板填充式生成，3种策略，输出已优化为"可直接执行"但仍偏泛
4. **UI**（`app.py`，23KB）— 输入→分析→3个标签页展示，简洁但缺乏对话引导
5. **已知问题**：线程安全问题、中文桌面路径、未使用的全局引擎实例

关键技术约束：
- Python 3.12+，customtkinter 5.x，Pillow
- 目标用户：各行业非技术背景人群
- 分发方式：单文件exe（PyInstaller），双击即用
- 运行时：完全离线，不依赖网络API

## Constraints

- **离线运行**: 运行时绝不能依赖外部API或网络连接 — 所有知识包固化在exe中
- **单文件分发**: 最终产物是一个<50MB的.exe文件，双击即用，无需安装
- **中文优先**: 所有交互界面和知识包内容为中文
- **Windows兼容**: 支持 Windows 10/11 中文系统
- **性能**: 知识分析+提示词生成必须在 2 秒内完成
